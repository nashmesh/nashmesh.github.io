What is MQTT?

MQTT is a message-broker application that mesh nodes can connect to. By connecting to an MQTT server, all LoRa traffic your node sees is sent to our MQTT server where applications can pull and use it.

MeshCore Analyzer Observer

An Observer is a MeshCore node that reports packets it hears to the MeshCore Analyzer, helping map network coverage and reliability across the region. Observers can be repeaters, room servers, or companion devices, and can stop sharing data at any time.

To set up your node as an observer, visit the Observer Onboarding page for step-by-step instructions.

Use the following configuration to connect your observer to the NashMesh MQTT server:

[general]
iata = "BNA"
[[broker]]
name = "nashmesh"
enabled = true
server = "mqtt.nashme.sh"
port = 1883
transport = "tcp"
keepalive = 60
qos = 0
retain = true
[broker.auth]
method = "password"
username = "meshdev"
password = "large4cats"

Experimental Observer Firmware

Custom firmwares provided by Adam include observer functionality built directly into the firmware, no companion device or separate install needed. Both repeater and room server variants are available.

Flash them from the web-based observer flasher, which stays up to date with the latest mainline and dev-branch builds automatically and lists all supported devices:

Open the Observer Flasher

For full documentation on all available settings and commands, see the MQTT Bridge Implementation docs.

Radio Settings

If this is a fresh flash or full erase, configure radio parameters for the NashMesh region:

set radio 910.525,62.5,7,8

set tx 22

Device Identity

Set your node's name and the Nashville IATA code:

set name MyObserver

set mqtt.iata BNA

WiFi

set wifi.ssid YourNetworkName

set wifi.pwd YourPassword

Add NashMesh and TennMesh

Slot 1 is pre-configured for LetsMesh Analyzer. Replace slot 2 (LetsMesh EU) with TennMesh, and add NashMesh to slot 3:

set mqtt2.preset tennmesh

set mqtt3.preset nashmesh

Reboot

reboot

After rebooting, verify your connections with:

get mqtt.status

If connected successfully, each configured preset will show ok.

If you would like to still help with contributing your nodes data but do not want to connect to MQTT, please set OK to MQTT to true.

This allows any MQTT gateway (a node connected to MQTT) to submit your data to our MQTT server. For more information on enabling OK to MQTT, check out Meshtastic's website.

Reminder

It's preferred that MQTT is used only for collecting and displaying data from nodes. To keep the system running smoothly for everyone, we kindly ask that you leave MQTT downlink turned off on all public channels. This helps reduce unnecessary traffic on the server.

Setup Images

Provided are images showing each required change that is needed to setup MQTT.

First navigate to the Settings tab. For iOS, this option is on the bottom of the screen.

Then access the Channels option.

Click on the Primary Channel to configure settings for it.

Enable Uplink Enabled to allow MQTT to upload data the radio receives.

Navigate to the Settings tab again. For iOS, this option is on the bottom of the screen.

Click the MQTT module to configure settings for it.

Set Enabled for MQTT and enable Encryption Enabled. If your radio depends on your phones cellular network for internet connectivity, enable MQTT Client Proxy.

Set the Root Topic and MQTT server details.
