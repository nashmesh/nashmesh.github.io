NashMesh currently supports two platforms:  <img src="../../static/images/meshtastic-logo.svg" class="page-title-logo" alt="Meshtastic"><a href="https://meshtastic.org">Meshtastic</a> and <img src="../../static/images/meshcore-logo.png" class="page-title-logo" alt="MeshCore"><a href="https://meshcore.io">MeshCore</a>.

Choosing a platform is dependent on what you're looking for as both provide different values for the mesh network. Both projects are open-source and have a wide-array of contributers.

If you would like to see what nodes are around you based on platform, check out our <a href="/map">network map</a>.

## <img src="../../static/images/meshtastic-logo.svg" class="page-title-logo" alt="Meshtastic">Meshtastic

Meshtastic is a mesh platform started by Kevin Hester. It was the first platform that kick-started the idea of creating a mesh network using LoRa-based devices.

GitHub repository: <a href="https://github.com/meshtastic/firmware">meshtastic/firmware</a>

## <img src="../../static/images/meshcore-logo.png" class="page-title-logo" alt="MeshCore">MeshCore

GitHub repository: <a href="https://github.com/meshcore-dev/MeshCore">meshcore-dev/MeshCore</a>
