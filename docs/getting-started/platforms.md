## <img src="../../static/images/meshcore-logo.png" class="page-title-logo" alt="MeshCore">MeshCore
MeshCore is NashMesh's primary platform. It is a decentralized and encrypted mesh network using LoRa technology, built around two types of nodes: Companions and Repeaters.

<h3 class="no-anchor">Features</h3>

* Companion nodes transmit and receive user data and can optionally act as a repeater.

* Repeater nodes extend coverage by routing packets toward their destination. Unlike Meshtastic repeaters, they do not retransmit every packet they receive.

MeshCore uses AES encryption and supports up to a 64-hop limit for packets, making it well suited for communication that extends beyond a single region. Our current goal is to link up with the MeshCore network in East Tennessee and eventually across multiple states.

## <img src="../../static/images/meshtastic-logo.svg" class="page-title-logo" alt="Meshtastic">Meshtastic
Meshtastic is a community-supported platform on NashMesh. While it is no longer our primary focus, community members are welcome to continue running Meshtastic nodes and connecting to the network.

Meshtastic uses LoRa radios to build a decentralized ad-hoc mesh network. Packets are relayed across nodes with a 7-hop limit and encrypted using AES-256.
