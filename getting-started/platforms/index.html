What is MeshCore?

MeshCore is NashMesh's platform. It is a decentralized and encrypted mesh network using LoRa technology, built around two types of nodes: Companions and Repeaters.

If you would like to see what nodes are in your area, check out our network map.

Features

  • Companion nodes transmit and receive user data and can optionally act as a repeater.

  • Repeater nodes extend coverage by routing packets toward their destination. Unlike flood-based mesh networks, they do not retransmit every packet they receive.

MeshCore uses AES encryption and supports up to a 64-hop limit for packets, making it well suited for communication that extends beyond a single region. Our current goal is to link up with the MeshCore network in East Tennessee and eventually across multiple states.
